# Learning profile

An AI skill for answers that are easier to use when reading, writing, numbers, or starting the work is hard.

Same facts. Shorter path. One textbook picture. No talking down.

This public copy has no personal health details. Turn on the barriers that fit the learner.

## What it does

- One plain answer, then an example, then one labeled picture.
- Steps you can do one at a time.
- Numbers shown step by step.
- A draft you can copy when you have to write.
- IEP and Section 504 notes for K-12.
- A disability-office note for college. A high-school plan does not transfer.
- One YouTube link if a video teaches it better. Still pictures if YouTube has no clip.

## How to use it

1. Copy this folder into your AI skills directory as `learning-profile`.
2. Ask a normal question. You should not have to ask for the format.
3. If an answer misses, say the one part that was hard. Add that line to `SKILL.md`.

# Answer pattern

Read this when the reply is a lesson, a worked number problem, something they must write, or a note about access.

## Lesson

```
This reply does one thing: [the job].

[One sentence answer.]

Example: [one real case]

[One textbook figure. Caption: one sentence saying what the picture shows.]

What that means
- [point]
- [point]

Do this
1. [one action — start it if you can]
2. [one action]

Stop after step 2 if this is a long topic.

Key point: [same answer, new words, one sentence.]
```

## Number problem

```
This reply does one thing: the result, then the steps.

Answer: [result] [unit] — [what it means in words]

| What | Number |
| --- | --- |
| [label] | [value] |

Steps
1. [start number] means [words].
2. [operation] because [reason]. Result: [number] [unit].
3. Check: [reverse step]. Same number? Yes/no.

Key point: [result in words].
```

## Writing task

Give the draft. They should not have to build it.

```
This reply does one thing: a draft you can send.

Subject: [filled]

[3–5 short sentences, already written]

Change only these if you want:
- [blank label]: ___
- [blank label]: ___
```

Then one line: "Send as-is, or tell me the blank to fill."

## Plan note

Pick the block from the learner. Read `references/plans.md` first. Do not invent a diagnosis, a plan date, or a provider name.

K–12 IEP or 504. Parent or student can paste this to the team.

```
This reply does one thing: words for the school meeting.

Learner: K–12
Plan to ask about: [IEP if they need special instruction / 504 if they need access only]

Goal: [the real skill, unchanged]

Barrier: [reading / writing / numbers / starting / holding the steps]

Access to request:
1. [one support]
2. [one support]
3. [one support]

Note:
[4 short sentences. If a parent is asking, "my child." If the student is asking, "I."]
```

College. Student sends this. Say the old plan does not transfer.

```
This reply does one thing: a note for disability services.

Learner: college
Plan: no IEP. Register with disability services.

Goal: [the real course task, unchanged]

Barrier: [plain words]

Access to request:
1. [one support]
2. [one support]

Note to send:
[4 short sentences, first person]
```
